# 项目摘要

这是一个基于 Next.js 框架的现代 Web 应用项目，主要用于构建东方命理 AI 平台。项目采用 TypeScript 开发，使用 Tailwind CSS 进行样式设计，并部署在 Cloudflare Workers 平台上。

## 技术栈
- **前端框架**: Next.js 15.3.3 (React 全栈框架)
- **运行时**: Node.js 22.20.0 / Cloudflare Workers
- **语言**: TypeScript 5.8.3
- **样式**: Tailwind CSS 4.1.1
- **数据库**: Cloudflare D1 (SQLite)
- **部署**: Cloudflare Workers
- **适配器**: @opennextjs/cloudflare 1.3.0

## 主要功能
- 用户认证和会话管理
- AI 八字算命和命盘生成
- 响应式用户界面设计
- RESTful API 路由
- 数据库迁移和初始化脚本

## 项目特点
- 采用 App Router 架构实现客户端交互
- 支持静态资源优化
- 集成了 Cloudflare 生态系统
- 完整的开发和部署工具链
- 国风设计风格与现代技术融合
